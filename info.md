# Fear and Greed Index

Adds two sensors to Home Assistant with the current [Crypto Fear and Greed Index](https://alternative.me/crypto/fear-and-greed-index/) from alternative.me:

- **Numeric value** (0–100)
- **Text classification** (Extreme Fear / Fear / Neutral / Greed / Extreme Greed)

No API key required. Updates every 30 minutes.
